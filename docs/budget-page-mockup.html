What changed:
  1. Scope strip removed. The table below already shows exactly which lines this owner holds.
  2. Month header pinned. It stays put while scrolling, as does the line column and the total row — so you always know which month a cell belongs to.
  3. Departments and categories collapse, with a line count on each, and a Collapse all. 52 lines is a lot to scroll past to reach one.
  4. Categories drag to reorder by the ⠿ handle, within their department. The order is per budget owner — yours only, so it never changes what anyone else sees, and never changes the spend report.
  5. Add channel is permission-gated. Only people ticked for it in Users & access see the button — intended for admin, CEO, and the Retail and Marketing owners. Untick the box above to see the other state.
Worth deciding:
  1. Should sub-categories drag too, or only categories? Drawn as categories only — sub-category order matters less and doubles the drag targets.
  2. Should a new category added in Settings land at the top or bottom of an owner's existing order? Drawn as bottom, so a personal order is never silently rearranged.
  3. Collapse state is remembered per owner between visits — say if you'd rather it always open fully.
