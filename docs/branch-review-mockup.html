What this adds:
  1. Branch appears for New Store Investment too, not only Retail. The "Retail only" rule becomes a list of branch-split departments — it was deliberately hardcoded, so this is the change that revisits it.
  2. New Store Investment offers branches that aren't open yet. Fitting out a store happens before it trades, so the picker must include signed-but-unopened doors — Another Story today. Retail keeps its stricter rule: active, or closed in a year it traded.
  3. Shared is a real value, distinct from (no branch). Shared is a decision; no branch is an absence. Collapsing them would lose the difference between an answer and a gap.
  4. The review screen corrects attribution, not money. It writes the branch directly with an audit row — it does not reopen a PAID request or route through the edit-request approval flow.
  5. Suggestions are hints, never applied. A store named in a description is a clue; a human confirms it.
Worth deciding:
  1. Should the ex-"All branch" requests — travel between stores, bulk consumables, uniforms, currently in (no branch) — be moved to Shared? They are exactly what Shared is for, and it would be a small migration rather than manual review.
  2. Who can use the review screen? Drawn as admin and the department's budget owner. A BO correcting their own department's attribution seems right; a BO correcting another's does not.
  3. Should Branch become required for New Store Investment as it is for Retail, or stay optional there?
